# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests. Use GitHub's **Report a vulnerability** feature on this repository if it is enabled. Otherwise, contact the repository owner privately through GitHub and include steps to reproduce the issue. Avoid sending real passwords, tokens, or customer data in the report.

## Secret exposure

If a credential is exposed, revoke or rotate it immediately. Removing it in a later commit does not remove it from Git history; treat it as compromised and follow GitHub's guidance for removing sensitive data from a repository when needed.
